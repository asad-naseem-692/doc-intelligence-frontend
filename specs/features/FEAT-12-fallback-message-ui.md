# Feature: Fallback Message Display (UI)
**Owner:** Frontend | **Module:** Question & Answer

## Goal
Clearly show when the system couldn't find an answer, instead of it
looking like a broken response.

## Scope
- When the backend returns a fallback response, style it distinctly
  (e.g. a neutral/info style, not an error style) with the message
  "Couldn't find enough information in your documents."
